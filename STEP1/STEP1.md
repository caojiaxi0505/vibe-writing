# STEP1

对指定方向相关论文进行全面的调研，形成调研报告；调研应满足以下约束：

1. 调研的论文不早于2025年1月1日（硬性要求）

2. 调研的总论文数应不少于500篇（硬性要求）

3. 调研的论文中应不少于50%来自于ICML/NeurIPS/ICLR三大顶会（硬性要求）

4. 调研的论文应保持真实可求证，你需要使用webfetch/websearch工具，在arXiV平台找到abs页链接，才能认为对应论文真实存在（硬性要求）

调研的流程你应该参考下面的建议：

1. 500篇论文可能会“撑爆”上下文，你可以将500篇的调研任务拆解为50个子任务，每次调研10篇左右，将10篇调研任务交由subagent完成

2. 每个子任务的调研方向应保持一致，但多个子任务调研到的论文应进行去重，保证去重后的调研总论文数不少于500篇

3. 子任务的调研结果应该在STEP1目录下及时保存，保存为jsonl格式，命名为sub_task{i}.jsonl，其中i表示第i个子任务，jsonl中每行保存论文标题，abs页链接，论文摘要，论文主要贡献，论文结论，使用的benchmarks

4. 在完成所有子任务后，你需要将所有子任务的调研结果合并，形成最终的调研报告，保存到STEP1目录下，命名为report.jsonl，其中每行保存论文标题，abs页链接，论文摘要，论文主要贡献，论文结论，使用的benchmarks，并剔除重复的论文，随后删除所有子任务的调研结果

5. 你需要在完成调研任务后，对调研结果进行全面分析，形成分析报告，保存到STEP1目录下，命名为analysis.md，重点分析目前的研究热点，以及未来的研究方向，你应该具有洞察力地分析未来可能做出贡献的方向，这也将为我们的总任务即撰写一篇学术论文提供方向，该分析报告应主要用中文完成，但相关术语应该使用英文

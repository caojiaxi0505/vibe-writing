# 任务

撰写一篇学术论文，投稿至ICML 2027/NeurIPS 2026/ICLR 2027，方向为针对大语言模型的强化学习，论文的质量应远高于往届ICML/NeurIPS/ICLR接收论文的平均水平，你需要按照下面的流程推进任务

## 流程概述

step1：对指定方向相关论文进行全面的调研，形成调研报告；

step2：根据step1的结果，选取baseline和benchmark，构建baseline主表格；

step3：发挥想象力，提出一个“逻辑上非常make sense，但没人探索过”的新方法；

step4：找到一个成熟的开源代码库，用于实现step3的方法，并扩充baseline主表格，形成最终的main result表格；

step5：全面地进行消融实验，形成消融实验表格；

step6：全面完成论文的写作；

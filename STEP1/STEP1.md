# STEP1：文献调研与分析

目标：围绕“RL for LLMs”完成系统性文献调研，形成可验证、可追溯、可分析的结构化语料与分析报告。

## 必须项（MUST）

1. 调研论文发表/公开时间不得早于 **2025-01-01**。
2. 去重后论文总量不少于 **500 篇**。
3. 调研论文中，来自 **ICML / NeurIPS / ICLR** 的比例不少于 **50%**。
4. 每篇论文必须可验证：需提供 **arXiv abs 页面链接**（作为真实性校验依据）。

## 建议流程（SHOULD）

1. 将 500 篇任务拆解为 50 个子任务，每个子任务调研 **8–12 篇**。
2. 子任务间保持主题一致，并进行跨子任务去重。
3. 每个子任务输出保存为 `STEP1/sub_task{i}.jsonl`（`i` 为子任务编号）。
4. `jsonl` 每行字段建议包含：
   - 论文标题
   - arXiv abs 链接
   - 论文摘要
   - 主要贡献
   - 结论
   - 使用 benchmarks
5. 全部子任务完成后，合并为 `STEP1/report.jsonl`，并删除 `sub_task*.jsonl` 中间文件。
6. 基于 `report.jsonl` 生成分析报告 `STEP1/analysis.md`：
   - 重点分析当前研究热点；
   - 归纳未来研究机会点；
   - 建议按“研究主题 → 代表工作 → 主要瓶颈 → 潜在突破方向”结构组织；
   - 主体中文撰写，关键术语保留英文。

## 交付物（DELIVERABLES）

- `STEP1/report.jsonl`
- `STEP1/analysis.md`
